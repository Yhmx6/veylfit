# 映衣间 Windows 测试版 0.2.1

运行 Veylfit-Setup-0.2.1-windows-x64.exe，为当前用户安装。不需要预装 Python、MakeHuman 或配置生图 API。开始菜单可打开映衣间，安装时可选择桌面快捷方式。安装器尚未签名，Windows 可能提示未知发布者；只使用仓库 Release 的文件并核对 SHA256。

## 人物建档

填写性别、身高、体重、年龄，依次选择整体体型、手臂、胸腹、臀腿、肩颈。当前几何路径仅验证成年男性；女性资料可保存草稿。

四围两长均可不填或只填已知项目，单位为厘米：

| 项目 | 测量方式 |
| --- | --- |
| 胸围 | 胸部较丰满处水平一周，正常呼吸 |
| 自然腰围 | 肋骨与骨盆间自然腰部，不用裤腰尺寸替代 |
| 腹围 | 肚脐水平一周，不收腹 |
| 臀围 | 臀部最丰满处水平一周 |
| 肩宽 | 左右肩峰间直线宽度，不含上臂外侧 |
| 腿内长 | 站立裆点到地面的垂直高度，不用裤子内缝长度替代 |

导入正侧全身照，正常站立、头脚完整、薄而合身的衣物；不要求脱衣。处理后检查照片标记。已填尺寸在照片校正后施加，结果页“查看尺寸拟合结果”列出输入、模型和差值。异常组合会拒绝产生新模型；照片冲突会提示复核。

尺寸拟合是模板对应位置的几何约束，不是三维扫描。软件采用固定模板测量位置及肩峰/裆点近似标记；模型数值接近输入不代表真人各处精度达到相同水平。四围两长也不能完全决定身体形状。留空继续使用体型和照片估计。

## 确认人物与试衣

1. 进入面部与体型确认，导入本人正脸和侧脸参考。
2. 导出体型/面部校准素材包，手动交给所选择的聊天生图工具；结果导回后依次确认体型、正脸和侧脸。
3. 固定人物版本，进入试衣搭配，选择真实衣物试穿或搭配推荐。
4. 导入衣物、填写资料，选择效果及允许的配色，导出试衣包。
5. 手动生成后回到试穿记录导入，分别检查脸、体型和衣物。生成结果默认待确认，不自动替换人物基准。

真实衣物试穿不为了显瘦改色改版；搭配推荐可以按明确目标优化服装，不改变真实人体。当前通用衣物入口为单主图与同件细节；多件套装和自由场景组合尚未界面化。

## 保存与卸载

保存为 `.veylfit-person`，包括表单、照片、后台模型、人物确认、试衣任务和结果。支持导入旧 `.veylfit` 建档及旧人物项目；缺失资料保持未知。修改人物资料会要求重新确认，旧试衣任务保留当时版本。

文件由用户选择位置保存，可能包含私密照片，请自行保管。软件不会自动上传；手动提交素材包给生图服务意味着把包内素材交给该服务。如果保存到同步目录，系统可能自行同步。

通过 Windows“已安装的应用”卸载。卸载移除程序文件，不删除用户保存的档案；本地错误日志在 `%LOCALAPPDATA%\Veylfit\logs`。应用内不含任何真人模板。

## 开发验证

`Veylfit.exe --self-test <报告.json>` 在本机用合成图片测试模型加载、六项尺寸、人物档案、试衣包和回存。不会调用生图服务，不验证真实面部相似度。它只在显式运行时执行。
