# 原型迁移计划

2026-11-13更新：通用源码已迁入src/veylfit，Windows 0.2.0安装包已构建并完成本机隔离环境验收，见[发布验收](发布验收-0.2.0.md)。原本地测试者档案仍保持私有，不随迁移发布。以下迁入顺序保留为后续迁移检查依据。

## 迁入顺序

1. 盘点Python模块、运行时和依赖。优先导入独立可运行的体型向导，再整合照片、面部、人物候选及衣物流程。
2. 替换个人目录、样例人物默认值、依赖旁边工作目录的隐式路径，提供可配置资产目录。
3. 区分项目自写代码、第三方代码、人体模板、权重、AI插画和真人数据；为前五类逐项核对来源/许可/再分发条件。真人资产不迁入。
4. 建立依赖锁定及安装说明；模型体积、许可或权重不适合入库时给出明确获取步骤和校验值，不假装开箱即用。
5. 用合成/通用资料做最小样例，校验保存恢复、版本失效、导出绑定、任务失败及未知文件处理。
6. 在干净环境验证启动，重新输出可以公开的验收证据，再更新README的运行说明和状态。

## 必须保留的行为

五步主动选择、可返回、无白模展示、无肩颈滑杆；独立项目保存不覆盖固定人物；旧数据schema兼容；头部/下颌形变保护；版本绑定与过期结果屏蔽；脸与体型分项确认；生成来源如实记录。

## 禁止随迁内容

真人正侧/面部照片、个人测量值、个人白模/人物底图、外部穿搭照片、测试ZIP和生成输出、令牌、API密钥、缓存、日志、电脑绝对路径。不要直接执行整个旧目录的`git add`。

迁移完成条件：文档列出的启动命令实际可用，许可来源齐全，隐私检查通过，核心行为测试通过，README明确当前支持范围。几何模型对真实人体的准确性仍需要独立验证。
