## 尚未验证与当前边界

本轮是在开发者当前Windows机器上隔离Python环境完成，**尚未在另一台全新机器上安装测试**。未进行多机显卡/CPU/杀毒软件兼容性验证，也未新生成照片或作真人脸部主观确认。

成年男性建模路径为当前测试范围；女性及未成年资料可存草稿。生图仍需手动导出和回存。多件衣物组合、任意场景动作界面和自动生图不是本版功能。

升级与卸载测试的是程序目录外的用户文件。请不要把个人档案保存在安装目录内。
