# 映衣间 · Veylfit：PRD 产品需求文档

版本：0.1.11（真实衣物与搭配双模式）｜2026-11-12｜配套：[产品与技术方案](产品与技术方案.md)。

## 1. 用户、目标与范围

面向希望知道衣服穿在自己身上是否好看、适合什么场合的用户。第一阶段验证真实感照片试衣的闭环；用户决定审美目标，不仅凭性别、年龄或体重断定其想显瘦、显高或成熟。

MVP包含：档案采集、手绘外形选择、可选尺寸、正侧照片、后台体型、面部原照、逐步人物校准（三候选为备选）、分项确认、衣物导入、一次试穿及结果回存。用户界面不展示白模，不要求所有测量，不加入肩颈滑杆。

非范围：医疗或体脂评价、精确尺码保证、真实布料仿真、社交发布、自动下单、无限制支持任意生图API。衣橱与自动搭配在后续阶段。

## 2. 用户流程与逐步要求

| 步骤 | 输入与交互 | 完成条件 |
| --- | --- | --- |
| 1 基本资料 | 性别、身高、体重、年龄 | 本人填写或明确确认；数值和单位有效 |
| 2 整体体型 | 偏胖/正常/偏瘦三张手绘示意 | 主动选择，自动进入下一步 |
| 3 四个部位 | 手臂→胸腹→臀腿→肩颈，各三选一 | 每步仅当前三卡；可上一步修改 |
| 4 补充尺寸 | 胸、自然腰、脐腹、臀围；肩宽、腿内长 | 可部分填或全部跳过；留空不是0 |
| 5 全身照片 | 正面、真正侧面各一张 | 同期体型，头脚完整，清晰可判读 |
| 6 体型处理 | 后台构建与必要纠错 | 失败给出原因，不让用户修复杂三维模型 |
| 7 体型及面部逐步校准 | 确认正侧体型后，先校准正脸、再校准侧脸 | 各阶段分别确认；三候选可作探索备选 |
| 8 固定人物 | 形成已确认正面/正侧参考，历史斜侧兼容 | 保存版本，关键输入改变后重新确认 |
| 9 导入衣物 | 单品图、整套穿搭参考图 | 用户确认要试的衣物，区分衣服与原模特 |
| 10 试穿与回存 | 场景、风格、自然姿态表情 | 结果归属正确版本，认可或标注失败原因 |

拍摄引导：正常站立、自然呼吸，不收腹挺胸；手臂略离躯干；薄、合身、不塑形着装；避免厚外套与明显遮挡，不要求内衣/裸露。尽量固定相机和站位，避免明显俯仰与超广角近拍。无法补齐时保存草稿。

“肩宽”与“腿内长”使用明确测量示意；其定义见技术方案。全身照脸部不清楚时补充面部参考，不把模糊人脸放大当成可靠身份细节。

## 4. 状态与交互规则

用户主状态：资料草稿→外形选择完成→照片待检查→体型待确认→正脸待确认→侧脸待确认→人物已固定→可试衣。缺照片可存草稿，不能冒充完整建档成功。

“保存选择”不是“本人认可体型”。模型内部需要带骨架A姿势，人物确认图采用普通基础衣着；不展示白模也必须让用户有机会发现错误体型。三候选需要脸/体型独立确认，均完成后才选为基准。

返回修改保留不受影响的输入；改变整体类别使局部选择需要重新确认；改变体型或面部参考使候选/人物基准进入待复核，而不是静默替换既有试穿历史。实测值和照片冲突时提示复核，不自动覆盖。

自然表现：严肃、中性、轻微微笑等可轮换，禁止夸张/极端表情。目光明确指向前方路径、镜头、正在查看的物件或交流对象；不要每张机械直视镜头。动作服务场景，身体体量不随姿势或衣服开合无故变化。

## 5. 质量与非功能要求

- NFR01 本地资料优先，外部生成前明确上传范围与服务去向；不默认公开素材。
- NFR02 后台任务不阻塞选择界面；取消/过期结果不覆盖当前版本。
- NFR03 图像输入限制大小、尺寸和格式并实际解码；存档防路径穿越与资源过量。
- NFR04 一次结果同时检查脸、体型、衣物、手部/四肢和场景合理性，不只评分画质。
- NFR05 不把固定网格拟合容差宣传为真人测量准确度，不以单人成功宣称男女胖瘦高矮通用。
- NFR06 记录候选接受率、人物保持率、衣物关键特征错误、平均尝试次数、耗时、成本；目标阈值在小样本基线之后制定，不伪造已有达标数据。
- NFR07 原始身体/脸部照片、个人模型、生成结果、缩略图和备份的删除可追溯；日志排除个人图片和密钥。

## 当前逐步人物校准 v1（2026-11-12）

当前推荐路径为：建档与照片体型校正 → 补本人正脸/侧脸原照 → 确认同衣着同背景的正侧体型图 → 原始正脸局部校准并确认 → 原始侧脸加已确认正面辅助校准并确认 → 固定双角度版本 → 按角度独立试衣与回存。三张候选保留为探索备选，不再要求默认每次重生三个人物。

体型确认不批准脸部；正脸确认不批准侧脸。分别确认脸像本人和体型/衣着/背景保持。原始面部照片为身份依据，合成目标只提供身体与场景；只校正头脸、眼镜、发型并作必要颈部融合。微侧原照没有提供的90度轮廓仍需模型推断，本人视觉接受不等于精确重建。

改原照或体型参考重做全流程；改体型图撤销后续；改正脸撤销侧脸与基准；改侧脸保留体型与正脸；改衣服只重审本次试衣。请求绑定来源指纹、阶段和ID；拒绝输入图原样冒充结果，保存/重开核对记录。记录检查不是自动人脸相似性验证。历史结果绑定当时版本，不随当前基准变化。

本地新增逐步页面、建档至人物项目衔接、正侧角度区分和旧项目兼容。已有获本人认可的正侧校准图固定为新版本，模板入口已实际切换。新增5组流程/真实Tk/Windows入口检查和原10项回归检查通过；未做全人群或真人测量精度验证。试衣每次从固定图出发，不串联上一张试衣结果，不自动替换人物基准。

生图仍为聊天内置工具的人工交接；本地只负责导出包、导回、确认和保存。无自动API、无新增身份训练。待讨论：真实90度照片、局部掩膜和脸外变化检查、更多体型与女性验证、失败局部重试、源码迁入及自动生成服务。

## 视觉松量建议 v1（2026-11-12）

衣物尺寸未知时，AI建议“略宽松 / 常规 / 偏修身”的目标穿着观感，不能判断具体实物偏大偏小，不能输出品牌尺码、虚构厘米数或承诺真实合身。判断结合已确认正侧体型、服装品类/版型/厚薄、叠穿及用户偏好；身高体重不能直接推导尺码，也不默认某种体型必须显瘦。
